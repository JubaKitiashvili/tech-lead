# Model facts the plugin depends on

Each row is one outside fact that a rule in this plugin rests on, with the
page it comes from and the day it was last read there. `scripts/facts-check.mjs`
reads this table; `references/facts-check-prompt.md` is the brief for
re-checking it. A fact that changed is a reason to open a pull request, not
to edit a rule on the spot.

| id | Fact | Used in | Source | Checked |
|----|------|---------|--------|---------|
| price-per-token | Per million input/output tokens: Fable 5.2 $8/$40, Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50 for prompts up to 100K tokens. Fable 5.2 costs twice Opus 5.5 per token. | SKILL.md "Fable leads at most" | https://claude.dev/blog/which-claude-model-should-you-build-with/ | 2026-11-11 |
| aliases | In Claude Code the aliases `opus`, `sonnet` and `haiku` resolve to Opus 5.5, Sonnet 5.5 and Haiku 5.5; the `haiku` alias needs Claude Code 2.1.293 or later and stays Haiku 4.5 on Bedrock, Google Cloud and Foundry. | SKILL.md "Use aliases, not model IDs" | https://code.claude.com/docs/en/model-config | 2026-11-10 |
| effort-defaults | Default effort: Opus 5.5 `medium`; Haiku 5.5 `medium`; Sonnet 5.5 and Fable 5.2 `high` on the API and `medium` in Claude Code. | SKILL.md "Effort before tier", "Pin effort on delegates" | https://claude.dev/blog/which-claude-model-should-you-build-with/ | 2026-11-11 |
